# Beetroot Traffic Light (Module 02)

We are creating a **traffic light program** for an STM32 microcontroller. The firmware
cycles a single traffic light through its phases using fixed timings.

## Hardware

| Parameter       | Value                          |
|-----------------|--------------------------------|
| MCU             | **STM32F411CEU6**              |
| Family / Core   | STM32F4, ARM Cortex-M4F        |
| Package         | UFQFPN48                       |
| Flash / RAM     | 512 KB / 128 KB                |
| System clock    | 16 MHz (HSI)                   |

## Algorithm

The traffic light repeats the following sequence in an endless loop:

| # | Phase              | Duration   |
|---|--------------------|------------|
| 1 | Green              | 30 seconds |
| 2 | Green blinking     | 3 seconds  |
| 3 | Yellow             | 2 seconds  |
| 4 | Red                | 30 seconds |
| 5 | Red + Yellow       | 1 second   |

After phase 5 the cycle starts again from phase 1. One full cycle takes **66 seconds**.

```
 ┌─► GREEN (30 s) ─► GREEN BLINKING (3 s) ─► YELLOW (2 s) ─┐
 │                                                         │
 └──────── RED + YELLOW (1 s) ◄──────── RED (30 s) ◄───────┘
```

## Project structure

```
Core/          Application code (main.c, interrupts, HAL config)
Drivers/       STM32F4 HAL and CMSIS drivers
cmake/         Toolchain files
*.ioc          STM32CubeMX configuration
```

## Build

The project is generated by STM32CubeMX with the CMake toolchain.

```sh
cmake --preset Debug
cmake --build --preset Debug
```
